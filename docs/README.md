# CampusOS --- Phase 0 Documentation

This folder contains the five authoritative documents required before
implementation begins.

## Documents

1.  `01_PRD.md` --- Product requirements, scope, MVP, users, USP and
    success criteria.
2.  `02_SRD.md` --- Software requirements, data model, APIs, security,
    PWA and SOLID requirements.
3.  `03_ARCHITECTURE.md` --- System architecture, module boundaries,
    dependency direction and scalability.
4.  `04_UX_DESIGN.md` --- Student/admin UX, workflows, visual rules and
    responsive behavior.
5.  `05_ANTIGRAVITY_GITHUB_EXECUTION.md` --- Exact operating contract
    for Antigravity, task ownership, branches, PRs, phases and
    acceptance gates.
